# AI Helpdesk Frontend

React + TypeScript + Vite. Instalarea, API-ul, Docker și limitele sunt documentate în [README-ul principal](../README.md).

```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Testele de browser necesită PostgreSQL-ul dedicat și dependențele Python de test, conform README-ului principal.
